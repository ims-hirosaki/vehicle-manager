# 09 FAQ・トラブルシューティング・既知の注意点

> 対象: 車両管理プラグイン v1.0.0。ユーザー向け（Q&A）とエンジニア向け（注意点・改善候補）の両方を含む。

## 第1部 FAQ（ユーザー向け）

### 操作全般
**Q. 左メニューに「車両管理」が表示されません。**
A. 閲覧権限（`access_custom_plugins`）がないアカウントです。管理者に権限付与を依頼してください。

**Q. 「権限がありません。」と表示されて保存/削除/CSV取込できません。**
A. 画面は見られても、編集権限（`edit_custom_plugins`）がありません。管理者に依頼してください。

**Q. 「一連指定番号」とは何ですか？「車番」と何が違いますか？**
A. 本システムでは同じものです。車両を一意に識別する番号で、他のシステム（運行日報など）が車番として参照します。同じ番号は登録できません。

**Q. 一連指定番号を間違えて登録しました。直せますか？**
A. 車両一覧の「編集」から変更できます。ただし、他システムで旧番号を使った記録との関連は自動では更新されません。

**Q. 車台番号が「全角NG」になります。**
A. 全角の英数字・ハイフン（－）・スペースが混じっています。半角の英数字と `-`、`_` のみ使えます。コピー&ペースト時に混入しやすいので打ち直してください。

**Q. 運輸支局/分類番号/用途区別の選択肢に目的の値がありません。**
A. 「車両管理 > マスタ管理」で追加してください。

**Q. マスタの項目が削除できません（ボタンが灰色）。**
A. その項目を使っている車両が1台以上あります。該当車両を別の値に編集してから削除してください。「使用車両数」列で件数を確認できます。

**Q. マスタの名前を変更したい。**
A. 名前変更の機能はありません。新しい名前を追加し、該当車両を編集（またはCSV上書き）で付け替え、旧項目を削除してください。

**Q. 車検切れ間近の車両だけ見たい。**
A. 一覧の「有効期限」で「有効期限間近（30日以内）」を選びます。すでに切れたものは「期限切れのみ」です。

**Q. 有効期限が空の車両が絞り込みで出てきません。**
A. 仕様です。期限が未入力の車両は、期限での絞り込みでは表示されません。有効期限を入力するか「すべて」を選んでください。

**Q. 日付を入力したのに、保存後に空になっていました。**
A. 読み取れない書式です。「令和5年4月1日」「平成30年12月31日」「昭和63年1月1日」または「2023-04-01」の形式で入力してください。「令和元年」は「令和1年」と書きます。「2023/4/1」「R5.4.1」は使えません。

**Q. 削除してしまった車両を元に戻せますか？**
A. 戻せません。再登録するか、バックアップから復元が必要です。

### CSV一括登録
**Q. Excelで作ったCSVは使えますか？**
A. Shift-JIS（通常のCSV保存）でも UTF-8 でも取り込めます。ただし日付は和暦またはYYYY-MM-DD形式の文字列にしてください。Excelが自動で `2023/4/1` に変換した日付は空になります（セルの書式を文字列にするか、和暦で入力）。

**Q. 取込結果の「スキップ」は何ですか？**
A. 車台番号が空の行と、重複（同じ一連指定番号が既にあり、モードが「スキップ」）の行です。

**Q. 上書きモードで取り込んだら、CSVに無い項目が消えました。**
A. 仕様です。上書きは全項目を更新するため、CSVに列が無い/空欄の項目は空になります。取込前にバックアップし、全列を含むCSVを使ってください。

**Q. 「INSERT 失敗」エラーが出ます。**
A. 運輸支局・分類番号・用途区別のいずれかが空の可能性が高いです。この3列は必須です。メッセージ末尾のDBエラー内容も確認してください。

**Q. 「高さ」だけ取り込まれません。**
A. CSVの見出しを `高さ(cm）`（開きは半角`(`、閉じは全角`）`）にしてください。他の見出しは両方とも全角括弧です。

**Q. プレビューにエラー行が出ません。**
A. 仕様です。エラーは「インポート実行」後の結果画面に「○行目: …」で表示されます。

**Q. 入力補助ボタン（タグ）の内容が変わりました。**
A. CSV取込のたびに、登録データから3台以上で使われている値を自動的に作り直します。

## 第2部 トラブルシューティング（エンジニア向け）

| 症状 | 原因候補 | 確認/対処 |
|---|---|---|
| メニュー非表示 | `access_custom_plugins` 未付与 | ロール/ユーザーへ付与（付与の仕組みはこのプラグイン外） |
| 保存時「権限がありません。」 | `edit_custom_plugins` 未付与 | 同上。表示権限だけ持つユーザーで発生 |
| 保存/削除で 403 | nonce 失効（ページを長時間開いたまま） | 画面を再読込して再操作 |
| 画面のスタイル崩れ | `employee-manager` の共通CSSが無い | 本プラグインのCSSのみで動作はする。見た目統一には当該プラグインが必要 |
| 古いJS/CSSが残る | バージョン定数が変わらずキャッシュが効く | 強制リロード、または `VM_VERSION` 更新 |
| タグが初期値のまま/消えた | `vm_tag_data` はCSV取込でのみ更新・置換 | CSV取込後は3件以上の値のみ。必要なら `VM_Vehicle::rebuild_tags()` 呼出 |
| 日付が NULL で保存 | 日付書式が非対応（`wareki_to_date`） | 書式を確認。非対応書式は黙って NULL |
| 一覧の車番順が不自然 | `serial_number` が文字列型（"100" < "35"） | 仕様。数値順にするにはSQL/型の変更が必要 |
| 運輸支局の絞り込みに出る値とマスタが違う | 絞り込みは車両データ由来、マスタは別管理 | 仕様 |
| CSV取込でタイムアウト/失敗 | ファイルが大きい、PHPの `upload_max_filesize`/`max_execution_time` | サーバー設定の調整、CSVの分割 |
| CSV文字化け | CP932でも UTF-8 でもないエンコーディング | UTF-8 か Shift-JIS で保存し直す |

## 第3部 既知の注意点・仕様上の癖（ソース解析で判明した事項）

エンジニア・運用者向け。バグかどうかは運用判断だが、**仕様として理解しておくべき挙動**。

| # | 事項 | 影響 | 場所 |
|---|---|---|---|
| N1 | 権限チェックが画面とAJAXで異なる（表示=`access_custom_plugins`、保存等=`edit_custom_plugins`）。マスタ管理のPOSTは `edit_custom_plugins` を確認しない | 閲覧権限のみのユーザーでもマスタ変更が可能 | `class-admin-menu.php`, `vehicle-master.php` |
| N2 | CSVの高さ見出しが `高さ(cm）`（括弧が半角/全角混在）で定義 | 全角括弧のCSVでは高さが取り込まれない | `class-vehicle.php` の `$col_map` |
| N3 | 日付変換は和暦文字列とISOのみ対応、変換不能は黙ってNULL。「元年」「全角数字」「`/` 区切り」は不可 | データ欠落に気付きにくい | `wareki_to_date`, `wareki_to_ym` |
| N4 | CSV上書きは34列すべてを更新対象にする（CSVに無い列はNULL化） | 既存データの意図しない消去 | `ajax_csv_import` |
| N5 | CSV取込で運輸支局・分類番号・用途区別の必須/マスタ整合を検証しない | NOT NULL違反でINSERT失敗、またはマスタ外の値が混入 | 同上 |
| N6 | CSV：セル内改行非対応（先に行分割）。トランザクションなし | 一部のみ反映される可能性 | 同上 |
| N7 | 乗車定員: フォームで空欄→0、CSVで空欄→NULL。DBの既定値(2)は明示的な値指定により効かない | 経路ごとに値が異なる | `sanitize_post`, `ajax_csv_import` |
| N8 | 登録フォームで空の文字列項目は空文字（NULL でない）、CSV は空→NULL | 集計時の空判定の違い | 同上 |
| N9 | `ajax_save` は更新時にID存在確認をしない | 存在しないIDの更新は成功扱い（0行更新） | `ajax_save` |
| N10 | 「期限間近=30日」が3か所に重複記述 | 変更時の修正漏れ | `class-vehicle.php`, `vehicle-list.php`, `vehicle-form.php` |
| N11 | 有効期限の基準日は PHP `date()`（サーバー時刻）であり、WordPress のタイムゾーン設定（`wp_date`/`current_time`）を使っていない | サーバーTZがUTCだと日本時間の早朝は前日扱い | `expiry_status_where`, 画面 |
| N12 | 一連指定番号は VARCHAR(20) の文字列。並べ替えは文字列順 | "100" が "35" より前 | DB設計 |
| N13 | 年月のみの和暦変換は1989年1月を平成扱い（日付版は1989-01-08から） | 昭和64年1月の年月表示が1日〜7日分ずれる | `ym_to_wareki` |
| N14 | 和暦の「元年」表示は「1年」 | 表示慣習との差異 | `date_to_wareki` |
| N15 | `rebuild_tags` はCSV取込時のみ実行され、結果で置換。小文字の車台番号接頭辞は対象外。末尾の `arsort($prefix_cnt)` は結果に影響しない（並べ替え後の変数が使われていない） | タグの鮮度・初期タグ消失 | `rebuild_tags` |
| N16 | 車両一覧の `order` パラメータは検証前に大文字化。`orderby` はサニタイズ済み許可リスト。ページ番号は `max(1, …)` | 問題なし（安全） | `vehicle-list.php` |
| N17 | CSV画面の `#vm-import-btn`（インポート実行）は常に非表示で、実質未使用 | UIの残骸 | `vehicle-csv.php`, `admin.js` |
| N18 | 車両フォームの「自動車の種別」「自家用・事業用の別」は自由入力のテキスト欄 | 表記ゆれの可能性 | `vehicle-form.php` |
| N19 | マスタに削除済みの値を持つ車両は、編集画面ではその値が選択肢に残るが、マスタ管理画面にはその値の行が無い（使用数の確認ができない） | 孤立した値が増える | `vehicle-form.php` |
| N20 | `uninstall.php` は全データを削除する。バックアップ機構・論理削除・監査ログなし | 誤操作時に復元不可 | `uninstall.php`, `ajax_delete` |
| N21 | プラグインのバージョン定数が変更されていない（1.0.0固定）。DB マイグレーション機構なし | スキーマ変更時に手動対応が必要 | `vehicle-manager.php`, `class-db-install.php` |

## 第4部 改善候補（参考）
- CSVの高さ見出しの揺れを許容（全角/半角括弧の正規化）、日付の `YYYY/M/D` 対応
- 上書きモードを「CSVに存在する列のみ更新」に変更
- マスタ管理POSTにも `edit_custom_plugins` を要求
- 日付変換失敗の明示的なエラー表示、CSVのプレビューでエラー行表示
- 有効期限の基準を WordPress のタイムゾーンに統一、期限間近日数の定数化
- 車両削除の論理削除・履歴化
