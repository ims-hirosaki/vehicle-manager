# 02 操作マニュアル（ユーザー向け）

> 対象: 車両管理（WordPress 管理画面の「車両管理」メニュー）を使う業務担当者
> 専門知識は不要です。画面の指示に沿って操作してください。

## 0. はじめに

- 左側の管理メニューに「**車両管理**」（車のアイコン）があります。クリックすると次の4つの画面に移動できます。
  1. **車両一覧** — 登録済みの車両を見る・探す・編集する・削除する
  2. **車両登録** — 新しい車両を1台ずつ登録する
  3. **CSV一括登録** — 車検証データのCSVファイルをまとめて取り込む
  4. **マスタ管理** — 選択肢（運輸支局・分類番号・用途区別）を増やす・減らす
- メニューが見えない場合は、閲覧権限がありません。管理者に権限付与を依頼してください。
- 「登録」「更新」「削除」「CSV取込」を行うには、さらに編集権限が必要です。権限がないと「権限がありません。」と表示されます。

## 1. 車両一覧を見る・探す

1. 左メニュー「車両管理 > 車両一覧」をクリック。
2. 画面上部に「車両一覧」と**登録件数**（例: 45件）が表示されます。
3. 1ページに **20台** 表示されます。下部の「‹ 前へ」「次へ ›」や番号でページを移動します。

### 表示される列
運輸支局 / 分類番号 / 用途区別 / 一連指定番号 / 登録年月日 / 初度登録年月 / 有効期限満了日 / ブレーキ / リーフスプリング / 操作（編集・削除）
※ 日付は和暦（令和○年○月○日）で表示されます。

### 絞り込み
- **運輸支局**: プルダウンで選ぶと、その運輸支局の車両だけ表示（選ぶと自動で反映）。
- **有効期限**:
  - 「すべて」: 絞り込みなし
  - 「期限切れを除く」: 有効期限が今日以降の車両
  - 「有効期限間近（30日以内）」: 今日から30日以内に切れる車両
  - 「期限切れのみ」: すでに有効期限が過ぎた車両
- 絞り込み中は「クリア」ボタンで解除できます。
- 注意: **有効期限が未入力の車両**は、「期限切れを除く」「30日以内」「期限切れのみ」のどれを選んでも表示されません（「すべて」でのみ表示）。

### 並べ替え
見出しの「運輸支局」「一連指定番号」「登録年月日」「有効期限満了日」をクリックすると並べ替えできます。もう一度クリックすると昇順（▲）/降順（▼）が切り替わります。初期表示は「一連指定番号」の昇順です。

### 色の意味（車検切れ防止）
| 表示 | 意味 |
|---|---|
| 行が薄い赤 + 赤いバッジ「期限切れ」 | 有効期限満了日が今日より前 |
| 行が薄い黄 + 黄色いバッジ「30日以内」 | 有効期限満了日が今日から30日以内 |
| 色なし | 30日より先、または期限未入力 |

## 2. 車両を新規登録する

1. 「車両管理 > 車両登録」、または車両一覧右上の「**新規登録**」ボタンをクリック。
2. 各セクションに入力します。**赤い印（必須）の項目は必ず入力**してください。

### 必須項目（5つ）
| 項目 | 入力方法 | 注意 |
|---|---|---|
| 運輸支局 | プルダウンから選択 | 選択肢が足りない場合は「マスタ管理」で追加 |
| 分類番号 | プルダウンから選択 | 同上 |
| 用途区別 | プルダウンから選択 | 同上 |
| 一連指定番号 | 文字入力（例: 35） | **他の車両と重複できません**（他システムの連携キー） |
| 車台番号 | 文字入力（例: FR1AH-105156） | **半角の英数字・ハイフン(-)・アンダースコア(_)のみ** |

- 車台番号は入力中に自動チェックされます。✔ が出れば OK、✖ と赤い警告が出たら全角文字が混じっています（全角ハイフン「－」やスペースにも注意）。

### 日付の入力
- 「登録年月日」「初度登録年月」「有効期限満了日」は、**カレンダーから選ぶ**か、**「令和5年4月1日」のように直接入力**できます（`2023-04-01` の西暦形式もOK）。
- 初度登録年月は「令和5年4月」または `2023-04` の形式です。
- カレンダーで選ぶと和暦欄が自動で埋まり、和暦を入力して欄の外をクリックするとカレンダーが連動します。
- 読み取れない形式（例: 「R5.4.1」「令和5年4月」を日付欄に入力）は**エラーにならず空欄として保存**されます。必ず保存後に確認してください。

### 入力補助（タグ）
- 「車名」「型式」「原動機の型式」「車台番号」「リーフスプリング」の入力欄の上に、よく使う値のボタン（タグ）が並びます。
- クリックすると、**入力欄の現在の内容の末尾に追加**されます（例: 車台番号でタグ「FR1AH-」をクリックし、続きに「105156」を入力）。
- タグは、CSV一括登録を実行するたびに、登録データから自動的に作り直されます（3台以上で使われている値が対象）。

### 初期値が入っている項目
自動車の種別=普通 / 自家用・事業用の別=事業用 / 乗車定員=2名 / 燃料の種類=軽油。必要に応じて変更できます。

### 選択式の項目
- 用途: 特種 / 貨物
- 車体の形状: 冷蔵冷凍車 / バン
- ブレーキ: ドラム / ディスク
- 燃料の種類: 軽油 / ガソリン / LPG / 電気 / ハイブリッド

### 数値項目
最大積載量・車両重量・車両総重量（kg）、長さ・幅・高さ（cm）、前前軸重・前後軸重・後前軸重・後後軸重（kg）は整数、総排気量・定格出力（kw / L）は小数点以下2桁まで。空欄でも保存できます。

3. 画面下部の「**登録する**」をクリック。
4. 「保存しました。一覧に戻ります...」と表示され、約1秒後に車両一覧へ移動します。

### よくあるエラー
| メッセージ | 対処 |
|---|---|
| 運輸支局は必須です。（分類番号・用途区別・一連指定番号・車台番号も同様） | 未入力の項目を入力 |
| 車台番号は半角英数字・ハイフン・アンダースコアのみ使用できます。 | 全角文字を半角に直す |
| 一連指定番号「○○」はすでに登録されています。 | 別の番号にする、または既存車両を編集 |
| 権限がありません。 | 編集権限の付与を管理者に依頼 |
| 通信エラーが発生しました（HTTP ○○○） | 時間をおいて再実行。続く場合は管理者へ |

## 3. 車両情報を編集する

1. 車両一覧の該当行の「**編集**」をクリック。
2. 登録時と同じ画面が開き、現在の値が入っています（日付は和暦表示）。
3. 有効期限が切れている/30日以内の場合は、有効期限満了日の下に警告メッセージが出ます。
4. 修正して「**更新する**」をクリック。
- 運輸支局・分類番号・用途区別が、マスタから削除済みの値であっても、編集時にはその値が選択肢に残るので失われません。

## 4. 車両を削除する

1. 車両一覧の該当行の「**削除**」をクリック。
2. 確認画面「一連指定番号 ○○ の車両を削除しますか？ この操作は取り消せません。」で「**削除する**」をクリック。
3. 削除後、一覧が再読込されます。**元に戻せません**。誤って削除した場合は、再登録（またはCSV取込）が必要です。

## 5. CSVでまとめて登録する

詳細な列名・ルールは `06_CSV一括登録仕様.md` を参照。ここでは手順のみ示します。

1. 「車両管理 > CSV一括登録」を開く。
2. CSVファイルを枠にドラッグ&ドロップ、または「ファイルを選択」で指定。
3. 「重複時の処理」を選ぶ:
   - **スキップ**（初期値）: すでに同じ一連指定番号の車両があれば、既存データをそのまま残す
   - **上書き**: すでにある車両を、CSVの内容で更新する
4. 「**プレビュー確認**」をクリック → 先頭10件と有効行の合計が表示される（この時点ではまだ登録されません）。
5. 内容がよければ「**上記内容でインポートを実行する**」をクリック。
6. 結果（新規登録／上書き更新／スキップ／エラーの件数）と、エラー行の詳細（「○行目: ○○」）が表示されます。
7. 「車両一覧を確認する」で結果を確認、「別ファイルを読み込む」で続けて取り込めます。

ポイント:
- 文字コードは Shift-JIS（Excel保存の標準CSV）でも UTF-8 でも自動判定されます。
- 1行目は見出し行（指定の列名）にしてください。
- 車台番号が空の行は黙ってスキップされます（エラー件数には数えられません）。
- プレビューは先頭10件のみ表示ですが、エラー行はプレビューでは表示されません。**エラー内容は実行後の結果画面で確認**します。
- 取り込み後、入力補助のタグが自動更新されます。

## 6. マスタ（選択肢）を管理する

「車両管理 > マスタ管理」では、運輸支局・分類番号・用途区別の3つの一覧を編集できます。ここで変えた内容は、車両登録フォームのプルダウンに反映されます。

| 操作 | 方法 | ルール |
|---|---|---|
| 追加 | 入力欄に入力して「追加」 | 運輸支局は50文字、分類番号・用途区別は10文字まで。空欄・重複は不可 |
| 並べ替え | 行の「↑」「↓」 | プルダウンの表示順が変わる |
| 削除 | 行の「削除」→確認 | **使用中（1台以上の車両が使っている項目）は削除できません**（ボタンが無効になります） |

- 「使用車両数」列で、各項目を使っている車両数がわかります。
- 初期値: 運輸支局=青森・熊本 / 分類番号=130・131・830 / 用途区別=あ・い・う・え・か・き・く・け・こ・を
