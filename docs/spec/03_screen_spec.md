# 03 画面仕様

> 対象: 車両管理プラグイン v1.0.0。管理画面は4画面。すべて WordPress 管理画面（wp-admin）内。
> 画面描画は `admin/views/*.php`、画面制御は `admin/assets/admin.js`、スタイルは `admin/assets/admin.css`（`vm-` 接頭辞）。

## 共通事項

| 項目 | 内容 |
|---|---|
| メニュー | トップレベル「車両管理」（アイコン `dashicons-car`、表示位置 28）。サブメニュー4つ。必要権限 `access_custom_plugins` |
| 権限不足時 | HTTP 403、メッセージ「権限がありません。」（`wp_die`） |
| アセット読込条件 | URL の `page` パラメータが `vehicle-manager` / `vm-vehicle-form` / `vm-vehicle-csv` / `vm-master` のときのみ CSS/JS を読み込む |
| JSへ渡すデータ | `vmData`: `ajaxUrl`, `formNonce`, `listNonce`, `csvNonce`, `tags`, `listUrl`, `formUrl` |
| 日付表示 | 画面では和暦、DB は西暦。令和=2019-05-01以降、平成=1989-01-08〜2019-04-30、それ以前は昭和 |
| 共通CSS | `wp-content/plugins/employee-manager/admin/assets/admin.css` が存在すれば先に読み込む（無くても動作） |

### メニュー構成

| メニュー名 | page パラメータ | 描画ファイル |
|---|---|---|
| 車両一覧 | `vehicle-manager` | `admin/views/vehicle-list.php` |
| 車両登録 | `vm-vehicle-form` | `admin/views/vehicle-form.php`（編集時は `&action=edit&id=N`） |
| CSV一括登録 | `vm-vehicle-csv` | `admin/views/vehicle-csv.php` |
| マスタ管理 | `vm-master` | `admin/views/vehicle-master.php` |

## 画面1: 車両一覧（`vehicle-manager`）

### URLパラメータ
| パラメータ | 値 | 既定 | 備考 |
|---|---|---|---|
| `transport_bureau` | 運輸支局名 | 空（全件） | 完全一致 |
| `expiry_status` | `valid` / `soon` / `expired` | 空 | 上記以外は無視（空扱い） |
| `orderby` | `serial_number` / `registration_date` / `expiry_date` / `transport_bureau` / `id` | `serial_number` | 許可リスト外は `serial_number` |
| `order` | `ASC` / `DESC` | `ASC` | |
| `paged` | 1以上の整数 | 1 | 1ページ20件 |

### 構成要素
1. **ヘッダー**: タイトル「車両一覧」、件数バッジ（絞り込み後の総件数）、「新規登録」ボタン（`vm-vehicle-form&action=new`）
2. **フィルターバー**: 運輸支局プルダウン（DBに実在する運輸支局のみ。`SELECT DISTINCT transport_bureau`）、有効期限プルダウン、「絞り込む」ボタン、フィルター適用中のみ「クリア」ボタン。プルダウン変更で自動送信
3. **一覧テーブル**（10列）

| 列 | 内容 | ソート |
|---|---|---|
| 運輸支局 | `transport_bureau` | ○ |
| 分類番号 | `classification_number` | × |
| 用途区別 | `purpose_category` | × |
| 一連指定番号 | `serial_number` | ○ |
| 登録年月日 | 和暦表示 | ○ |
| 初度登録年月 | 和暦表示（年月） | × |
| 有効期限満了日 | 和暦＋バッジ | ○ |
| ブレーキ | `brake` | × |
| リーフスプリング | `leaf_spring` | × |
| 操作 | 「編集」リンク、「削除」ボタン | － |

4. **行の色・バッジ**
   - 有効期限 < 今日: 行クラス `vm-row-expired`（薄赤 #fef2f2）+ バッジ「期限切れ」
   - 今日 ≤ 有効期限 ≤ 今日+30日: 行クラス `vm-row-warn`（薄黄 #fffbeb）+ バッジ「30日以内」
   - 有効期限が NULL: 色なし
5. **0件**: 「登録データがありません。」
6. **ページネーション**（総ページ > 1 のときのみ）: 「‹ 前へ」「次へ ›」、現在ページ±2の番号、「N件中 a〜b件を表示」。ソート・フィルター条件を引き継ぐ
7. **削除確認モーダル**: 「一連指定番号 ○○ の車両を削除しますか？ この操作は取り消せません。」[キャンセル][削除する]。オーバーレイクリックでも閉じる

### 削除の動作
「削除する」→ AJAX `vm_delete`（nonce: `vm_list_nonce`）→ 成功でページ再読込、失敗で `alert('削除失敗: …')`、通信失敗で `alert('通信エラーが発生しました。')`

## 画面2: 車両登録・編集（`vm-vehicle-form`）

- `action=edit&id=N` かつ該当IDが存在: 編集モード（タイトル「車両情報の編集」、ボタン「更新する」）。IDが存在しない場合「車両データが見つかりません。」で停止
- それ以外: 新規モード（タイトル「新規車両登録」、ボタン「登録する」）
- 保存は AJAX（`vm_save`）。成功で「保存しました。一覧に戻ります...」→ 1.2秒後に一覧へ。失敗は画面上部の通知エリアに表示

### フォーム項目（6セクション・34項目）

#### セクション1: 基本情報
| 表示名 | name | 入力種別 | 必須 | 補足 |
|---|---|---|---|---|
| 運輸支局 | `transport_bureau` | プルダウン（運輸支局マスタ） | ○ | |
| 分類番号 | `classification_number` | プルダウン（分類番号マスタ） | ○ | |
| 用途区別 | `purpose_category` | プルダウン（用途区別マスタ） | ○ | |
| 一連指定番号 | `serial_number` | テキスト | ○ | 一意。ヒント「外部参照キー。一意（重複不可）」 |
| 車台番号 | `chassis_number` | テキスト＋タグバー | ○ | 半角英数字・`-`・`_`のみ。入力中に ✔/✖ 表示 |

- 編集時、マスタに存在しない既存値（削除済み等）は選択肢に追加され保持される。

#### セクション2: 日付情報
| 表示名 | name | UI | 保存形式 |
|---|---|---|---|
| 登録年月日 | `registration_date` | カレンダー（`_picker`）＋和暦テキスト | DATE |
| 初度登録年月 | `initial_registration_ym` | 月ピッカー＋和暦テキスト | `YYYY-MM` 文字列 |
| 有効期限満了日 | `expiry_date` | カレンダー＋和暦テキスト | DATE |

- カレンダー変更→和暦欄を自動更新。和暦欄のフォーカスが外れた（blur）→カレンダーを更新（変換不能な文字列ならカレンダーは更新されない）。
- 編集時、有効期限満了日の下に警告表示: 期限切れ「有効期限が切れています。」（赤）／30日以内「有効期限まで30日以内です。」
- カレンダー用の `*_picker` 項目はサーバーで使われない（サーバーは和暦/ISOのテキスト欄のみ読む）。

#### セクション3: 車両情報
| 表示名 | name | 入力種別 | 既定値/選択肢 |
|---|---|---|---|
| 車名 | `vehicle_name` | テキスト＋タグ | 例: 日野 |
| 型式 | `model` | テキスト＋タグ | 例: 2PG-CD5CE |
| 原動機の型式 | `engine_model` | テキスト＋タグ | 例: GH11 |
| 自動車の種別 | `vehicle_type` | テキスト | 普通 |
| 用途 | `usage_type` | プルダウン | 特種 / 貨物 |
| 自家用・事業用の別 | `ownership_type` | テキスト | 事業用 |
| 車体の形状 | `body_shape` | プルダウン | 冷蔵冷凍車 / バン |
| 乗車定員 | `passenger_capacity` | 数値（1〜99） | 2 |
| 燃料の種類 | `fuel_type` | プルダウン | 軽油 / ガソリン / LPG / 電気 / ハイブリッド（既定: 軽油） |
| ブレーキ | `brake` | プルダウン | ドラム / ディスク |
| リーフスプリング | `leaf_spring` | テキスト＋タグ | 例: フロント板羽 |

「デフォルト: ○○」のバッジが付く項目は初期値が入る固定値フィールドだが、編集は可能。

#### セクション4: 重量・寸法（整数、min=0）
最大積載量 `max_load_kg`(kg)、車両重量 `vehicle_weight_kg`(kg)、車両総重量 `gross_weight_kg`(kg)、長さ `length_cm`(cm)、幅 `width_cm`(cm)、高さ `height_cm`(cm)

#### セクション5: 軸重（見出しは「軸重」だが総排気量もここに含まれる）
前前軸重 `front_front_axle_kg`、前後軸重 `front_rear_axle_kg`、後前軸重 `rear_front_axle_kg`、後後軸重 `rear_rear_axle_kg`（各 kg、整数）、総排気量・定格出力 `displacement`（kw / L、step 0.01）

#### セクション6: その他（テキスト、任意）
型式指定番号 `model_designation_number`、類別区分番号 `category_class_number`、原本名称 `original_name`、点検分類 `inspection_category`

#### フッター
[キャンセル]（一覧へ戻る）、[登録する/更新する]（送信中は「保存中...」で無効化）

### タグバー（入力補助）
- `.vm-tag-bar[data-target=項目名]` にタグ（`vmData.tags[項目名]`）をボタン表示。クリックで対応入力欄（`#field-項目名`）の**値の末尾に連結**して入力欄にフォーカス。
- 対象項目: `chassis_number`, `vehicle_name`, `model`, `engine_model`, `leaf_spring`
- 該当タグが無い項目はバーを表示しない。

## 画面3: CSV一括登録（`vm-vehicle-csv`）

### 構成要素
1. **フォーマット説明カード**: 文字コード、ヘッダー行、車台番号空行のスキップ、日付形式、全角車台番号のエラー
2. **ファイル選択カード**: ドラッグ&ドロップ領域（クリックでもファイル選択）、ファイル名表示
3. **オプション**（ファイル選択後に表示）: 重複時の処理（スキップ=既定／上書き）、[プレビュー確認] ボタン、[インポート実行] ボタン（※HTML上は存在するが常に非表示のまま。実際の実行はプレビュー後の確定ボタンから）
4. **プレビューエリア**: 「プレビュー（先頭10件）」、「有効行合計: N 件」、表（運輸支局・分類番号・用途区別・一連指定番号・車台番号・登録年月日・有効期限満了日・車名・型式）、[上記内容でインポートを実行する][キャンセル]
5. **結果エリア**: 新規登録／上書き更新／スキップ／エラーの件数、エラー詳細リスト（「N行目: メッセージ」）、[車両一覧を確認する][別ファイルを読み込む]
6. **ローディング**: 「プレビュー生成中...」「インポート中...」

### 画面遷移
ファイル選択 → オプション表示 → プレビュー → インポート確定 → 結果表示（別ファイルを読み込む で初期状態へ）

- ファイルを選び直すとプレビュー・結果は隠れる。
- プレビュー表の日付は DB 保存形式（西暦 YYYY-MM-DD）で表示される（和暦ではない）。
- 「有効行合計」は、エラー行・車台番号空行を除いた件数（重複かどうかは判定しない）。

## 画面4: マスタ管理（`vm-master`）

3つのカード（運輸支局マスタ／分類番号マスタ／用途区別マスタ）が縦に並ぶ。各カード:

- 追加フォーム: テキスト入力（maxlength＝50/10/10、プレースホルダ「例: 宮城」「例: 100」「例: さ」）＋[追加]
- 一覧テーブル: 項目名／使用車両数（「N 件」）／操作（↑ ↓ 削除）
  - 先頭行の↑、末尾行の↓は無効
  - 使用車両数 > 0 の項目は削除ボタン無効（ツールチップ「使用中のため削除できません」）
  - 削除時は JavaScript confirm「「○○」を削除しますか？」
- 注記: 「車両登録フォームの「○○」の選択肢に反映されます。使用中の項目は削除できません。」
- 結果通知: 成功「○○を追加しました。」「○○を削除しました。」／エラーメッセージ（空、文字数超過、重複、使用中）
- 通常のフォームPOST（ページ再読込）で処理。AJAXではない。
