# 車両管理プラグイン 仕様書セット — 索引と用語集

> 本ドキュメントはソースコード（バージョン 1.0.0）からのリバースエンジニアリングで作成した仕様書セットの入口です。
> NotebookLM / Gem のソースとして読み込み、エンジニア・一般ユーザー双方の質問に答えることを目的としています。

## 1. この仕様書セットの対象システム

- 名称: **車両管理**（WordPress プラグイン `vehicle-manager`、バージョン 1.0.0）
- 利用組織: 有限会社たんぽぽ運送（社内システム）
- 目的: 車検証に記載される車両情報の登録・管理、有効期限の監視、CSV一括取り込み、他プラグインへの車両情報提供
- 動作基盤: WordPress 管理画面（wp-admin）上のプラグイン。PHP + MySQL（WordPress の `$wpdb`）+ jQuery

## 3. AI（NotebookLM / Gem）向け回答ガイド

- **ユーザー（業務担当者）からの質問**には、まず `02_user_manual.md`、必要に応じて `03_screen_spec.md` と `09_faq_known_issues.md` を根拠に、専門用語（SQL・AJAX等）を避けて手順形式で答える。
- **エンジニアからの質問**には、`04_data_spec.md`・`07_api_integration.md`・`08_architecture_ops.md` を根拠に、ファイル名・クラス名・関数名・カラム名を明示して答える。
- 仕様として書かれていない事項は推測せず「ソースからは確認できない」と答える。特に、**WordPress の権限（ケイパビリティ）をどのロールに付与しているか**は本プラグインの外側（別プラグイン等）で定義されており、本資料では不明。
- 画面名・メニュー名は日本語表記（例: 「車両一覧」）、内部名（例: `vehicle-manager`、`vm-vehicle-form`）を併記してある。

## 4. 用語集

| 用語 | 意味 |
|---|---|
| 車両管理 | 本プラグイン名。WordPress 管理メニューにも「車両管理」と表示される |
| 運輸支局 | ナンバープレートを管轄する国土交通省の運輸支局（例: 青森、熊本）。マスタで管理 |
| 分類番号 | ナンバープレートの分類番号（例: 130, 131, 830）。マスタで管理 |
| 用途区別 | ナンバープレートのひらがな（例: あ、い、う…を）。マスタで管理 |
| 一連指定番号 | ナンバープレート下4桁（車番）に相当する番号として運用される識別子。**システム上は一意（重複不可）**で、他プラグインとの連携キー（外部参照キー）になる。「車番」とも呼ぶ |
| 車番 | 本システムでは「一連指定番号」と同義 |
| 車台番号 | 車検証の車台番号（例: FR1AH-105156）。半角英数字・ハイフン・アンダースコアのみ |
| 初度登録年月 | 最初に登録された年月（YYYY-MM で保存、和暦表示） |
| 有効期限満了日 | 車検の有効期限満了日。一覧で色分け・絞り込みに使用 |
| 型式 | 車両の型式（例: 2PG-CD5CE） |
| 原動機の型式 | エンジン型式（例: GH11） |
| 軸重 | 各軸にかかる重量。前前・前後・後前・後後の4箇所 |
| 型式指定番号 / 類別区分番号 | 車検証記載の指定番号・類別区分番号（任意入力） |
| 原本名称 | 車検証の原本に関する名称（任意入力） |
| 点検分類 | 点検区分（任意入力） |
| リーフスプリング | 板バネ（例: フロント板羽） |
| マスタ | 選択肢の一覧。運輸支局・分類番号・用途区別の3種類を画面から編集できる |
| タグ | 入力欄の上に並ぶクリック式の入力補助ボタン（車名・型式など）。CSV取込時に自動更新される |
| 和暦 | 令和・平成・昭和。日付入力・表示に使用し、DB には西暦で保存 |
| 期限間近 | 有効期限満了日が「今日〜30日後」の範囲 |
| 期限切れ | 有効期限満了日が今日より前 |
| プレビュー | CSV を DB に書き込まずに先頭10件を確認する機能 |
| nonce | WordPress の不正リクエスト対策トークン（利用者は意識不要） |
| ケイパビリティ | WordPress の権限名。本プラグインは `access_custom_plugins`（画面表示）と `edit_custom_plugins`（保存・削除・CSV取込）を使用 |
